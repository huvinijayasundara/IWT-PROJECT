# 🎉 Online Event Planning System

A full-stack **web-based event management platform** developed to simplify event planning, booking, and coordination between users, event planners, suppliers, and administrators.

This system enables seamless collaboration for organizing events such as weddings, parties, and corporate functions with real-time management of services, vendors, and deliveries.

---

## 🚀 Project Overview

The **Online Event Planning System** is designed to automate and streamline the entire event lifecycle — from event creation and booking to delivery of required items and administrative management.

It ensures efficiency, transparency, and better coordination between all stakeholders involved in event planning.

---

## ✨ Key Features

### 👤 User Module
- User registration and secure login  
- Browse and search events/services  
- Book events with customized preferences  
- View event summary and pricing  
- Receive booking confirmation via email  
- Track booking history  

---

### 🧑‍💼 Event Planner Module
- Create and manage new event plans  
- Assign services and vendors  
- Monitor budget and optimize costs  
- Suggest alternative vendors  
- Submit final event plan for approval  

---

### 🚚 Supplier Module
- View confirmed orders  
- Schedule deliveries  
- Track shipment progress  
- Update delivery status  
- Generate invoices automatically  
- Notify event planners upon completion  

---

### 🛠️ Admin Module
- Manage event planners (add / update / remove)  
- Maintain system users and roles  
- Validate and monitor system data  
- Ensure smooth system operations  
- Handle system errors and notifications  

---

## ⚙️ System Features
- Role-based access control (Admin, User, Planner, Supplier)  
- MVC architecture implementation  
- Secure authentication system  
- Real-time validation and updates  
- Responsive and user-friendly UI
